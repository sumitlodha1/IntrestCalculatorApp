# 💰 Interest Calculator App

## Description

Interest Calculator is an Android application designed to **calculate Simple Interest and Compound Interest** in an easy and user-friendly way. The app allows users to enter the **principal amount, interest rate, and time period**, and instantly displays the calculated result.

## How It Works

Users can choose between **Simple Interest** and **Compound Interest** using radio buttons. For compound interest, the app also provides a **special case option** where interest is calculated **monthly with yearly compounding**, making it useful for real-world financial scenarios.

## Key Highlights

The app features a clean interface with clear input fields and instant results. It uses **Kotlin** for implementation and basic Android UI components such as **EditText, RadioButton, Switch, and TextView**. Additional features like **clear input**, **currency-formatted output**, and **dynamic UI changes** improve usability.

This project is suitable for **learning Android fundamentals**, understanding user input handling, and implementing basic financial calculations in a practical application.
